# CNCF & KCNA 필수 핵심 용어사전 (Korean-English Glossary)

> KCNA 시험 지문과 CNCF 생태계 문서에서 반드시 마주치게 되는 필수 용어들을 명쾌하게 정리한 한·영 대조 용어집

---

## 1. 클라우드 네이티브 아키텍처 및 철학

- **Cloud Native (클라우드 네이티브)**: 확장 가능하고 장애 복원력이 뛰어나며 자주 변경할 수 있는 시스템을 구축하기 위해 컨테이너, 마이크로서비스, 불변 인프라, 선언적 API를 활용하는 접근 방식.
- **Twelve-Factor App (12-팩터 앱)**: 선언적 형식, 배포 환경과의 격리, 클라우드 수평 확장성 등을 달성하기 위해 12가지 원칙을 정의한 모던 SaaS 구축 방법론.
- **Immutable Infrastructure (불변 인프라)**: 배포 후 서버나 컨테이너를 직접 수정(패치)하지 않고, 변경이 발생할 때마다 새로운 이미지를 빌드하여 전체 교체하는 원칙.
- **Microservices (마이크로서비스)**: 하나의 대규모 앱을 독립적으로 배포 및 확장 가능한 작고 전문화된 서비스들로 분할하여 구성하는 소프트웨어 아키텍처.
- **Serverless (서버리스 / FaaS)**: 개발자가 서버 인프라를 직접 관리하지 않고 이벤트가 발생할 때만 코드를 실행하며, 자원을 0까지 축소(Scale-to-zero)할 수 있는 컴퓨팅 모델.
- **Stateless (무상태)**: 프로세스가 클라이언트의 세션 상태를 로컬 디스크나 메모리에 영구 보관하지 않고 모든 영속 데이터를 외부 백엔드 저장소에 위임하는 방식.
- **Declarative vs Imperative (선언형 vs 명령형)**: 원하는 최종 상태(Desired State)를 명시하는 방식(선언형)과 수행할 절차와 단계를 하나씩 나열하는 방식(명령형).

## 2. 쿠버네티스 아키텍처 & 리소스

- **Control Plane (컨트롤 플레인)**: 클러스터의 전역 결정을 내리고 이벤트를 감지 및 처리하는 관리 계층 (apiserver, etcd, scheduler, controller-manager).
- **Worker Node (워커 노드)**: 실제 애플리케이션 컨테이너를 호스팅하고 실행하는 물리/가상 머신 (kubelet, kube-proxy, 컨테이너 런타임).
- **Pod (파드)**: 쿠버네티스에서 생성 가능한 가장 작은 배포 단위. 동일한 네트워크 네임스페이스와 IP, 스토리지를 공유하는 하나 이상의 컨테이너 그룹.
- **Deployment (디프로이먼트)**: ReplicaSet을 통해 파드의 개수를 유지하고 무중단 롤링 업데이트와 롤백을 선언적으로 관리하는 상위 리소스.
- **StatefulSet (스테이트풀셋)**: 고유하고 영구적인 네트워크 식별자와 순차적 배포/확장, 전용 스토리지가 필요한 유상태 애플리케이션을 위한 컨트롤러.
- **DaemonSet (데몬셋)**: 클러스터의 모든(또는 특정) 노드마다 파드를 정확히 하나씩 항상 실행하도록 보장하는 컨트롤러.
- **Job & CronJob (잡 & 크론잡)**: 지정된 개수의 파드가 정상 종료(Exit 0)될 때까지 실행되는 일회성 및 주기적 배치 작업.
- **Service (서비스)**: 변화하는 파드들의 IP 집합에 일관된 단일 네트워크 진입점(가상 VIP 및 DNS 이름)을 부여하는 추상화.
- **Ingress (인그레스)**: 외부 HTTP/HTTPS 트래픽을 클러스터 내부의 특정 서비스로 라우팅하는 규칙과 SSL/TLS 종료를 정의하는 L7 게이트웨이.
- **ConfigMap & Secret (컨피그맵 & 시크릿)**: 일반 설정 텍스트(ConfigMap)와 Base64로 인코딩된 민감 정보(Secret: 암호, 토큰, 키)를 컨테이너 이미지와 분리하여 주입하는 리소스.
- **PersistentVolume (PV) & Claim (PVC)**: 클러스터에 영구 보존되는 물리적 스토리지 풀(PV)과 사용자가 필요한 용량/접근모드를 요청하는 바우처(PVC).
- **StorageClass (스토리지클래스)**: 관리자의 수동 개입 없이 PVC 요청 시 클라우드 디스크를 자동으로 생성해주는 동적 프로비저닝(Dynamic Provisioning) 템플릿.
- **RBAC (역할 기반 접근 제어)**: 역할(Role/ClusterRole)과 바인딩(RoleBinding/ClusterRoleBinding)을 통해 특정 주체(User, ServiceAccount)에게 최소 권한을 부여하는 보안 메커니즘.

## 3. 컨테이너 런타임 및 표준 인터페이스

- **OCI (Open Container Initiative)**: 컨테이너 이미지 형식(Image Spec)과 런타임 실행 형식(Runtime Spec)의 글로벌 개방형 표준을 제정하는 조직.
- **CRI (Container Runtime Interface)**: kubelet이 특정 런타임에 종속되지 않고 containerd, CRI-O 등 다양한 컨테이너 엔진과 통신할 수 있도록 만든 gRPC 표준 플러그인 인터페이스.
- **CNI (Container Network Interface)**: 리눅스 컨테이너 환경에서 네트워크 인터페이스를 연결하고 IPAM(IP 할당 관리)을 수행하는 플러그인 표준 (Calico, Flannel, Cilium).
- **CSI (Container Storage Interface)**: 서드파티 스토리지 벤더가 쿠버네티스 코어의 수정 없이 자체 스토리지를 볼륨 드라이버로 붙일 수 있게 지원하는 표준 인터페이스.
- **cgroups (Control Groups)**: 리눅스 커널에서 프로세스 그룹의 CPU, 메모리, I/O 자원 사용량을 제한하고 모니터링하는 기술.
- **Namespaces (네임스페이스)**: 리눅스 커널에서 시스템 리소스(PID, Network, Mount, IPC, UTS, User)를 프로세스별로 독립적인 뷰(View)로 격리하는 기술.

## 4. 관측 가능성 (Observability)

- **Metrics (메트릭)**: 시스템의 상태나 성능을 나타내는 수치형 시계열 집계 데이터 (CPU 사용량, 처리율, 에러율).
- **Prometheus (프로메테우스)**: Pull 모델 메트릭 수집, 시계열 데이터베이스(TSDB), PromQL 쿼리 언어 및 경보(Alertmanager)를 제공하는 대표 모니터링 시스템.
- **PromQL (프로메테우스 쿼리 언어)**: 다차원 레이블 데이터를 필터링, 집계, 계산하기 위해 프로메테우스가 제공하는 함수형 쿼리 언어.
- **Logs (로그)**: 특정 시점에 발생한 이벤트에 대한 텍스트/JSON 포맷의 상세 기록.
- **Fluentd & Fluent Bit**: 클라우드 네이티브 로그 수집, 파싱, 필터링 및 전달(Forwarding) 오픈소스 엔진.
- **Distributed Tracing (분산 추적)**: 마이크로서비스 간에 전파되는 단일 트랜잭션의 전 구간 호출 경로와 지연 시간(Latency)을 가시화하는 기술.
- **OpenTelemetry (OTel)**: 메트릭, 로그, 분산 추적 수집을 위한 단일 통합 표준 API 및 SDK를 제공하는 CNCF 핵심 프로젝트.
- **Span (스팬)**: 분산 추적 시스템에서 특정 서비스나 작업 단위가 소요한 시간과 메타데이터를 담은 기본 단위.
- **Jaeger**: CNCF Graduated 단계의 분산 추적 백엔드 및 시각화 플랫폼.
- **Grafana (그라파나)**: 프로메테우스, 로키 등 다양한 데이터 소스를 연동하여 직관적인 대시보드로 시각화해주는 플랫폼.

## 5. 애플리케이션 전달 & GitOps

- **GitOps (깃옵스)**: Git 리포지토리를 선언적 인프라 및 애플리케이션의 "단일 진실 공급원"으로 삼고, 클러스터의 컨트롤러가 이를 지속적으로 풀링하여 일치시키는 배포 운영 철학.
- **Argo CD & Flux**: GitOps 원칙에 따라 Git 매니페스트와 쿠버네티스 클러스터 간의 상태를 지속적으로 동기화(Reconcile)해주는 CNCF Graduated 프로젝트.
- **Helm (헬름)**: 쿠버네티스 리소스 매니페스트들을 단일 패키지(Chart)로 묶어 버전 관리, 배포, 롤백을 자동화해주는 패키지 관리자.
- **Chart (차트)**: Helm에서 패키지화된 쿠버네티스 리소스 정의 파일들의 번들.
- **Kustomize (커스터마이즈)**: 템플릿 문법 없이 기본(Base) YAML 파일에 환경별(Overlay) 차이점만 패치하여 매니페스트를 조합하는 도구 (`kubectl -k` 내장).
- **Harbor (하버)**: 이미지 저장, 역할 기반 접근 제어, 취약점 스캐닝, 디지털 서명 검증을 제공하는 오픈소스 OCI 아티팩트 레지스트리.
- **Trivy (트리비)**: 컨테이너 이미지, 파일시스템, Git 리포지토리의 OS 패키지 및 애플리케이션 종속성 취약점을 고속으로 스캐닝하는 보안 도구.
